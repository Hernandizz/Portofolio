## 🚀 Proyek Unggulan & Penelitian

### 1. 🤖 Chatbot Helpdesk Berbasis RAG & HID (Featured Research)
> Sistem chatbot cerdas kampus menggunakan teknik **Hierarchical Information Decomposition (HID)** dan **Retrieval-Augmented Generation (RAG)** untuk menjawab pertanyaan mahasiswa berdasarkan basis data dokumen PDF internal secara akurat dan minim halusinasi.
- **Tech Stack**: Python, LangChain, FastAPI, ChromaDB / FAISS

### 2. 🛍️ Platform E-Commerce Modern
> Marketplace full-stack yang dilengkapi fitur real-time chat antara pembeli dan penjual, integrasi payment gateway Midtrans, dan analytics dashboard untuk merchant.
- **Tech Stack**: React.js, Node.js, Express, MongoDB

### 3. 🎓 Sistem Informasi Akademik
> Portal akademik terintegrasi untuk manajemen data mahasiswa, penjadwalan kuliah otomatis, pengisian KRS, dan rekapitulasi nilai dengan role-based access control.
- **Tech Stack**: Laravel, MySQL, Bootstrap

### 4. 📊 Dashboard Analitik AI & Forecasting
> Dashboard visualisasi data prediktif yang memanfaatkan machine learning untuk forecasting tren bisnis dan analisis sentimen pengguna secara real-time.
- **Tech Stack**: Next.js, Python, TensorFlow, Chart.js

## 📦 Tentang Repository Ini (Portfolio & CMS)

Repository ini berisi website portfolio personal Hernandes yang dibangun menggunakan arsitektur **Earthy Professionalism** (palet warna Sage Green `#8FA28A`, Warm Cream `#F7F4ED`, dan Gold `#C8A96B`) serta dilengkapi **Backend Admin CMS** untuk mempermudah pengelolaan seluruh konten portfolio secara visual.

### 📁 Struktur Folder

```text
Compro/
├── data/
│   └── portfolio.json            # Database konten JSON (single source of truth)
├── public/                       # Berkas Frontend Publik
│   ├── css/
│   │   ├── styles.css            # Desain sistem Sage/Gold/Cream (Frontend)
│   │   └── admin.css             # Desain dashboard admin CMS
│   ├── js/
│   │   ├── main.js               # Client script frontend (Fetch & dynamic hydration)
│   │   └── admin.js              # Client script dashboard admin (Auth & CRUD)
│   ├── admin.html                # UI Dashboard Admin CMS
│   └── index.html                # UI Website Portfolio Utama
├── server/
│   └── index.js                  # Express.js REST API & Auth Server
├── assets/                       # Aset desain & dokumentasi referensi
├── .env                          # Konfigurasi password admin & session
├── .gitignore                    # Berkas yang diabaikan Git
├── package.json                  # Konfigurasi & dependensi Node.js
└── README.md                     # Dokumentasi profil & project
```
